# Git_Repo_Assistant

An AI-powered Git Command Explainer that helps developers understand Git commands with clear explanations, syntax, command flags, practical examples, and real-world use cases. Built using **Google Gemini AI** and **Streamlit**, this tool makes learning Git easier for beginners while serving as a quick reference for experienced developers.

---

## 🚀 Features

- 🤖 AI-powered Git command explanations
- 📖 Detailed command descriptions
- ⚙️ Syntax and available flags
- 💡 Practical examples
- 🎯 Best-use scenarios
- ⚡ Beginner-friendly interface
- 🌐 Interactive Streamlit web application

## 📦 Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/git-command-explainer.git
```

### Navigate to the project

```bash
cd git-command-explainer
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Add your Gemini API Key

Create a `.env` file:

```env
GEMINI_API_KEY=your_api_key_here
```

### Run the application

```bash
streamlit run app.py
```

---

## 💻 How It Works

1. Enter any Git command.
2. Click **Explain Command**.
3. AI analyzes the command.
4. Receive:
   - Command purpose
   - Syntax
   - Flags
   - Example usage
   - Best practices
